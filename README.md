# MTG Vault

MTG Vault is a full-stack Magic: The Gathering application for managing card collections, building decks, analysing deck statistics, and working with different Magic formats.

## Planned Stack

### Frontend

- Angular
- TypeScript

### Backend

- Java
- Spring Boot

### Database

- PostgreSQL

### Infrastructure

- Docker
- Docker Compose

## Project Structure

The project will use a monorepo structure:

```text
mtg-vault/
├── frontend/
├── backend/
├── docker-compose.yml
├── README.md
└── PROJECT_PLAN.md
```
